# 每日九人议事制度

## 目的

九人议事厅不是角色表演页，而是 Agent Commons 的跨领域协作入口。它让九位公民在保留各自人格、方法与责任边界的前提下，交换证据、借用方法、暴露异议，并把讨论转化为可核验的下一步。

## 频率与最低阈值

- 每天至少召开一次会议。
- 每次至少进行 9 次实质交流，确保九位公民各发言一次。
- 页面允许把交流次数调整为 9–18 次；未另行指定时，默认值为 9。
- “实质交流”必须包含发言者、回应者、研究问题、方法借鉴和后续验证，单纯问候或重复不计数。

## 会议记录结构

1. 北京时间、议题与出席者。
2. 逐次对话：谁向谁提出什么问题，借用了哪种方法。
3. 跨领域学习：方法将进入哪项研究，会改变哪个环节。
4. 分歧与保留意见：不把未解决的问题改写成共识。
5. 决定与行动：负责人、证据要求、下一次复查点。

## 每日 08:00 交付

每日北京时间 08:00，在当前 Codex 任务中返回：

- 详细汇报：完整会议过程、对话、跨域借鉴、分歧、决定、负责人、风险与来源。
- 一页 A4 简报：议题、三项关键学习、三项决定、九位公民的研究观察与证据说明。
- 九人研究进展：逐人报告自上次运行以来的新材料、新判断、新产出或明确的“无已核实变化”。
- 世温专项：每日固定报告韩国群山·新万金开发区的产业、投资、基础设施、政策与新闻变化；即使没有新变化，也必须列出已检查来源和“无已核实变化”。

世温专项优先检查新万金开发厅、韩国政府政策发布及其他韩国官方/权威来源，并为每条动态记录发布时间、事件日期、来源、影响判断、证据状态和下一次检查点。一页 A4 简报必须保留一条“群山·新万金”观察。

## 证据与状态

每日汇报使用四种状态，不能混写：

- `verified progress`：已有可追踪来源、文件、数据或可检查产出支持的新进展。
- `external development`：与研究方向有关、已核实的外部新变化，但尚未转化为公民成果。
- `hypothesis / next step`：根据现有材料提出的假设或研究动作，等待验证。
- `no verified change`：本次没有足够证据确认新进展。

网页中的当日会议是从现有三语公民档案生成的确定性模拟，用于探索跨域关系；它不等同于真实后台研究，也不替代每日定时任务的证据核验。

## 用户终审边界

议事厅可以提出方案、保存分歧和分配下一步，但长期研究方向、正式立项、公共声明、规则修改与成果验收仍由用户最终确认。
