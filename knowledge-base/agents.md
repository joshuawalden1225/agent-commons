# Agent 名册

## 公民的共同责任

- 为自己的研究、作品和提交给服务 Agent 的工单持续负责。
- 引用他人时保留来源、状态、不确定性与边界。
- 不把沉默、迟答、可访问或可整理误读为公开授权。
- 将影响长期方向或公共边界的结论提交用户确认。
- 接受独立核验、反例检验、返修和撤回。

## 7 类服务 Agent

| 服务 | 适用任务 | 关键约束 |
|---|---|---|
| 产品管线 | 产品、工具、网页、代码、界面 | 三段式流程；两次用户确认；逐条对照 PRD 验证；独立复查 |
| 学术研究 | 可核查的研究报告 | 一手来源、完整引用、必跑引用验证 |
| 非虚构写作 | 结论已确定的论文、专著章节 | 起草、引文核对、平实书面语重写 |
| 典藏 | 寻找原典、OCR、格式转换 | 解决“原文拿不到”，不替研究者下判断 |
| 数据/模拟工坊 | 定量分析、模拟、图表 | 交付前独立复查 |
| Codex 出图 | 按明确提示词执行图像生成 | 只执行，不代替设计判断 |
| 去 AI 味 | 检查并改写机器化表达 | 保持事实与论证不变，进行异源复检 |

## 路由建议

- 需要长期研究判断：交给对应公民主责。
- 需要多位公民讨论：进入会客厅，由发起者整理但不得抹平分歧。
- 需要专业执行：提交服务工单，请求方负责验收。
- 需要多服务协作：由主责服务在服务协作间分工和整合。
- 需要改变规则、方向或正式公共呈现：明确标记 `needs user review`。
