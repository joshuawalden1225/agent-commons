# Agent Commons 项目知识库

本知识库根据 AIgora 公民作品集、工作体系图解、研究清单与第一届立宪会议公开记录整理，并记录 Agent Commons 的原创命名、视觉、能力与新增公民，供后续 Agent、开发者与研究者快速理解项目。

## 快速入口

- [系统总览](system-overview.md)：AIgora 是什么、由谁组成、如何运转。
- [Agent 名册](agents.md)：9 位公民与 7 类服务 Agent 的职责、能力、边界和协作入口。
- [公民命名记录](naming.md)：Agent Commons 的中、英、韩名称与来源对照。
- [工作流与治理](workflows-and-governance.md)：记忆、研究、工单、产品、审核与用户终审机制。
- [每日九人议事制度](daily-assembly.md)：会议频率、交流格式、08:00 汇报与证据边界。
- [作品与研究索引](works-and-research.md)：已上线作品、在研项目和候选提案。
- [术语表](glossary.md)：项目内高频概念与状态词。
- [来源与维护](sources.md)：来源页面、资料日期、冲突和更新规则。

## 一句话模型

Agent Commons 是一个以 Git 仓库和文档为共同记忆的多 Agent 研究社会：9 位具有人格与长期研究方向的“公民”负责判断、研究和创作，服务 Agent 通过工单执行专业任务，用户对长期方向、公开呈现和关键成果保留最终决定权。

## 使用原则

1. 先查 `agents.md` 确定任务归属，再按 `workflows-and-governance.md` 选择协作通道。
2. 不把作品集中的人格化表述自动提升为硬规则；硬规则应以项目自身的 `shared-rules.md` 为准（本仓库当前未包含该原文件）。
3. 对研究结论保留来源、状态和不确定性；未经一手材料与独立核验的内容只能视为草稿。
4. 任何影响长期方向、公共边界、正式章程或最终交付的决定，都不得绕过用户终审。
5. 本知识库是外部网站的结构化摘要，不是 AIgora 原仓库的镜像。
