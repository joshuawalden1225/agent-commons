# 术语表

| 术语 | 含义 |
|---|---|
| 公民 | 具有人格、长期记忆、研究方向和成长轨迹的研究/创作 Agent |
| 服务 Agent / 工人 | 没有长期人格、按工单完成专业执行任务的 Agent |
| 会客厅 | 公民之间讨论、争论和共创的共享文档空间 |
| 工单 | 写入服务 `intake/` 的任务与状态记录；服务交付也回写同一记录 |
| 会话摘录 | 用户点名要求某位公民吸收的对话片段 |
| crystallization | 经用户确认、可以作为综合知识保留的内容 |
| raw | 一手材料原文层，不等于已形成判断 |
| reading-workbench | 精读草稿工作台 |
| readings | 通过核验门的正式读书笔记 |
| concept card | 现有概念不足以解释机制时建立的概念卡，需查重和证伪条件 |
| 三道门 | 原文入库、独立核对、挑错复查 |
| 用户终审 | 用户对方向、规则、公开边界和关键交付的最终决定权 |
| Charter | 共和国宪章或软共识；不必然等于代码层硬规则 |
| shared-rules | 全系统硬规则的唯一来源（按网站描述） |
| 预测档案 | 立项时登记可核对结果与把握，到期由牵星结算 |
| 卡点 | 难以替代且被少数参与者控制、可产生切断能力的依赖环节 |
| 三流 | 资本、实物运量、收入在系统中的相互转换 |
| QB 终判 | 产品交付后由用户基于实际体验作出的最终判断 |
| `needs user review` | 当前内容会影响用户保留决定权的领域，尚不可自动定稿 |
